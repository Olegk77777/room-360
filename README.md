# Room 360

[Открыть приложение](https://olegk77777.github.io/room-360/)

Съёмка сферической панорамы комнаты прямо в браузере телефона: камера, точки наведения, автоматический снимок после короткой остановки, локальный черновик и просмотр 360°. Без регистрации, сервера фотографий и установки через App Store.

## Как снять комнату

1. Откройте ссылку в Safari на iPhone или Chrome на Android. Разрешите камеру и движение.
2. Встаньте ближе к центру комнаты. Держите телефон вертикально, направьте его на стену и нажмите «Я готов».
3. Совмещайте зелёную точку с прицелом и замирайте примерно на секунду. Кадр снимается автоматически; можно отключить автоснимок и нажимать кнопку самостоятельно.
4. Пройдите 34 направления: 12 вокруг, 10 выше, потолок, 10 ниже и пол.
5. Соберите панораму, осмотрите её пальцем и сохраните JPEG. Отдельно скачайте исходники одним ZIP.

В маленькой комнате особенно важно **вращать телефон вокруг объектива, сохраняя положение объектива в пространстве**. Если обходить комнату или двигать телефон на вытянутой руке по кругу, близкие предметы на стыках будут расходиться. Не меняйте объектив и освещение во время серии.

Перед первым кадром нажмите «Камера» в верхней панели или кнопку с названием текущей камеры на экране подготовки. Выберите любой объектив, который браузер предоставил, и сразу оцените изображение. Реальные названия берутся из браузера; увеличение 0.5×/1× не угадывается по порядку списка. После первого кадра камера закрепляется до конца серии, чтобы не смешивать объективы. Выбор запоминается на устройстве, а новые черновики сохраняют использованную камеру. На устройствах без датчиков доступна ручная съёмка с приблизительными направлениями.

## Съёмка в версии 0.2

Видоискатель занимает весь доступный экран в портретном и горизонтальном положении. Изображение заполняет экран с центральной обрезкой предпросмотра; исходный кадр сохраняется полностью. Координаты прицела и точки учитывают этот масштаб.

Если направление выходит за видимую область или попадает под элементы управления, у края появляется стрелка с оставшимся углом поворота. Есть подсказки вверх/вниз и вправо/влево, в том числе при переходе от потолка к нижнему ряду. Автосъёмка и карта перенесены в «Настройки съёмки»; открытие настроек ставит съёмку на паузу.

## Что действительно делает приложение

- Получает снимки из видеопотока камеры до 1920 px по длинной стороне; это не полное разрешение штатной камеры iPhone.
- Использует фактическую ориентацию камеры (включая наклон и поворот изображения), проецирует кадры на сферу и смешивает перекрытия.
- Собирает JPEG 3072 × 1536, 2:1, с XMP GPano. Отображает долю пропущенных участков, если кадры не закрывают сферу.
- Держит обработку в отдельном Web Worker; фотографии декодируются по одной, память не растёт пропорционально всему набору несжатых кадров.
- Сохраняет каждый кадр в IndexedDB этого браузера. После перезагрузки можно продолжить, совместив камеру с опорным снимком. Потолочный снимок не используется для определения направления при продолжении.
- Останавливает автосъёмку при уходе в фон. Показывает ошибки разрешений и позволяет сохранить исходники независимо от успеха сборки.

**Это проекционная сборка по датчикам, а не распознавание и точное совмещение деталей фотографий.** Нет автоматического определения фокусного расстояния, оптимизации контрольных точек, коррекции параллакса и выравнивания экспозиции. Возможны двойные контуры и швы. Угол камеры по умолчанию 48° по короткой стороне, его можно менять при пересборке. Для более качественного результата исходники можно обработать в панорамном редакторе.

## Данные и обновления

Фотографии не отправляются ни на GitHub, ни в облако. IndexedDB принадлежит конкретному браузеру и устройству. Очистка данных сайта удаляет черновик; браузер тоже может освобождать локальное хранилище. Скачанный архив — независимая копия. При нехватке места приложение предупреждает, что нужно сохранить исходники до закрытия вкладки.

Веб-приложение доступно по HTTPS. Через меню Safari «Поделиться» → «На экран Домой» можно добавить значок. После публикации обновлений достаточно открыть или обновить страницу; service worker намеренно не кэширует старую версию. Полноценная работа без интернета после закрытия страницы не обещается.

## Разработка и публикация

Node.js 22.13+; React, TypeScript, Vite. Статический сайт, без Cloudflare/Next-сервера. Основа UI — локальные компоненты Base UI/Shadcn, оформление в `app/globals.css`.

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

`npm run lint` проверяет авторский код и настройки. Неизменённый каталог UI-компонентов исходного шаблона и его вспомогательные hooks рассматриваются как поставляемая библиотека; TypeScript проверяет их при сборке. Правила Next.js не используются, поскольку приложение работает на Vite.

После каждой проверенной правки — commit и push в `main`. GitHub Actions запускает тесты, проверку кода и сборку, затем публикует `dist` в GitHub Pages. Постоянное разрешение Олега на автоматический push закреплено в `AGENTS.md`.

## Проверено автоматически

Математика камеры и поворота экрана, переход через 0°/360°, зенит и надир, ортонормальность базиса, положение точки в видоискателе, полное покрытие сферы для разных пропорций камеры. Сборка синтетической сферы проверяется по пиксельной ошибке, включая полюса и шов. Отдельно проверяются архив исходников и XMP JPEG.

## Первый тест на реальном iPhone

Физическая камера и датчики iPhone в этой среде не проверены.

- Камера открывается; изображение заднее и не перевёрнуто.
- После «Я готов» первая точка оказывается в центре. При повороте телефона вправо следующая точка движется к центру слева относительно предыдущего положения на экране.
- При совмещении и остановке происходит ровно один снимок.
- После нескольких кадров проверить паузу, пересъёмку и перезагрузку страницы с продолжением по опорному кадру.
- Снять всю комнату, проверить потолок, пол, замыкание круга, дверные косяки и близкую мебель.
- Проверить сохранение JPEG через меню iOS и ZIP в «Файлы».

На первом реальном наборе следует проверить угол камеры, дрейф датчиков, резкость, экспозицию и качество стыков. Синтетические тесты не подтверждают качество реальной ручной съёмки.
