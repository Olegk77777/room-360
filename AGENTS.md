# Room 360

Веб-приложение для съёмки сферических панорам с телефона. Первый сценарий — небольшая комната Олега. Приоритет: простота, минимализм и работающая съёмка в Safari на iPhone.

## Публикация — постоянное разрешение Олега

- Все завершённые правки сразу проверять, коммитить и автоматически отправлять (`git push`) в GitHub этого проекта, без повторного запроса разрешения. Это прямое указание Олега от 7 сентября 2026 года.
- GitHub Pages должен автоматически обновляться после каждого push в `main`, чтобы Олег сразу тестировал на телефоне. Перед ответом проверять результат публикации и давать действующую ссылку.
- Не отправлять секреты, фотографии комнаты, пользовательские панорамы, локальные хранилища и временные файлы. Разрешение относится к исходному коду приложения и его публикации.
- Не использовать force push и не перезаписывать чужие изменения. При ошибке проверок исправить её перед push; не обходить проверки.

## Продукт

- Русский интерфейс. Съёмка по точкам, минимум настроек, удобство одной рукой.
- Камера и датчики включаются явным нажатием. Обрабатывать отказ, отсутствие датчиков, уход в фон и прерывание камеры.
- Исходники и черновик хранятся локально на устройстве. Никакой загрузки снимков на GitHub или сторонние серверы.
- Не выдавать проекционную сборку по датчикам за профессиональное распознавание и сшивку изображений. Для близких объектов возможны швы и параллакс.
- Математику направлений, проекции, покрытия сферы и обработку изображений проверять воспроизводимыми тестами. Реальную камеру и гироскоп проверяет Олег на телефоне; эмуляция не заменяет это.
- Сохранять относительные пути; новые инструкции и скрипты должны переноситься между машинами.
